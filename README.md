The student management site is a website that can manage handel student data. 

**Backend & Database Components ** 

Core python programming language handling application logic, server execution, and database connection handling. 

**Flask Framework:** Lightweight Web Server Gateway Interface (WSGI) framework used to build the HTTP server and serve API routing endpoints. 

**SQLite (student.db):** Lightweight, file-based relational database management system used for persistent storage of student records.
